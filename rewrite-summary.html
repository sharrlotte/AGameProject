2.Foundations & type consolidation

Before

  • Symbol interning via lasso; serde_json persistence.
  • Four overlapping block types: Block, BlockData, BlockState, Blocks.
  • Ship stats duplicated across ShipData, ShipState, ComputedShipStats.
  • No version check on load; malformed documents could reach gameplay.

After

  • All keys String; no lasso/serde_json; RON everywhere.
  • BlockPlacement, GridBlock, BlockRef, BlockOwner.
  • ShipGrid { blocks, cells } authoritative; ShipStats the single aggregate.
  • RonDocument/Versioned<T> reject unknown versions before use.

4.Save / load

Before

  • Per-ship files + index; five phantom ships padded on load; "repair" of ≤2-block designs.
  • No transforms, velocity, ammo, AI, drops, camera or RNG persisted.

After

  • Five slots saves/slot_N.ron, each a full WorldSave with embedded ships.
  • Designs in designs/*.ron; bundled starters seeded; no phantom ships.
  • Transforms, velocity, health, ammo, turret/pattern state, AI, battle, drops, camera, RNG.
  • Transients never serialized — cleared by DespawnOnExit(Game).

5.Power

Before

  • Duplicate PowerConsumer/PowerStorage; producer never inserted.
  • Only a demand total and ship-wide efficiency ratio; efficiency applied to every turret.

After

  • One PowerProducer { output } and EnergyConsumer { rate }.
  • Core 10, reactor 25; equal-share clamp(share / rate, 0, 1).
  • Only powered turrets are gated. Unpowered turrets fire normally; underpowered powered turrets cannot fire. Thrust disables at ≤0.01.

6.Targeting & combat

Before

  • All strategies aimed at blocks[0]; MostHP/EnemyBullet were placeholders.
  • No projectile ownership or point defense.
  • Beam visuals were children of the turret block while hitboxes used the rotating barrel.
  • Empty barrels could divide by zero; damage text at z = 1,000,000.

After

  • Core targeting; invalid core-less targets; Closest and real MostHP tie-breaks.
  • ProjectileOwner/Interceptable; point defense with lead prediction and missile priority.
  • TurretState { target, aim_point, can_fire } with barrel-forward fire gate.
  • Beams parented to the rotating barrel; laser axial offset fixed; damage text at layer 400.

7.AI profiles

Before

  • 11 BehaviorX markers + AIShipController; hard-coded transitions; inverted Flee.
  • Think rate in game.ron; behaviors not authorable per ship.

After

  • Inline RON AiProfile { initial, rules }; priority/cooldown evaluation.
  • One AiRuntime/AiBehavior; shared AI_THINK_RATE_HZ.
  • Targets reacquired on death/range; flee direction fixed; kamikaze removed.
  • Editor AI tab with presets, RON preview and validation.

8.Shared cargo

Before

  • Capacity/items on each storage block; non-atomic pickup; capacity loss unhandled.

After

  • Pooled in ShipStats; ShipChanged rebuilds capacity and discards excess.
  • Atomic pickup; player-only nearest-ship collection; cargo HUD with breakdown.
