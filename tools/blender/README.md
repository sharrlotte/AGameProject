# Blender Asset Scripts

This folder holds Blender Python scripts used to inspect, edit, and export game assets.

- Nothing here is shipped at runtime.
- Scripts operate on `game/assets/models/player.glb` and temporary working files.
- Every mesh, rig, or clip change must be previewed and approved before the final GLB is replaced.

See `docs/08-tooling-blender-mcp.md` for the Blender MCP setup.
